    API Reference

    Base URL: http://localhost:3000

    GET /

    Root endpoint. API-nin işlədiyini göstərir.

    Body: none
    200: Expense Splitter API is running
    curl http://localhost:3000/
    GET /health

    Service health status.

    Body: none
    200: {"status":"UP"}
    curl http://localhost:3000/health
    GET /version

    App version.

    Body: none
    200: {"version":"1.0.0"}
    curl http://localhost:3000/version
    POST /groups

    Create a new group.

    Body: {"name":"Weekend Trip"}
    201: created group
    400: {"message":"Group name is required"}
    curl -X POST http://localhost:3000/groups \
  -H "Content-Type: application/json" \
  -d '{"name":"Weekend Trip"}'
    GET /groups

    List all groups.

    Body: none
    200: group array
    curl http://localhost:3000/groups
    GET /groups/{groupId}

    Get group details.

    Path params: groupId
    404: {"message":"Group not found"}
    curl http://localhost:3000/groups/GROUP_ID
    POST /groups/{groupId}/members

    Add member to group.

    Body: {"name":"Ali"}
    201: created member
    curl -X POST http://localhost:3000/groups/GROUP_ID/members \
  -H "Content-Type: application/json" \
  -d '{"name":"Ali"}'
    POST /groups/{groupId}/expenses

    Add shared expense to group.

    Body: {"title":"Dinner","amount":90,"paidByMemberId":"...","participantIds":["..."]}
    201: created expense
    curl -X POST http://localhost:3000/groups/GROUP_ID/expenses \
  -H "Content-Type: application/json" \
  -d '{"title":"Dinner","amount":90,"paidByMemberId":"ALI_ID","participantIds":["ALI_ID","VELI_ID","AYSE_ID"]}'
    GET /groups/{groupId}/balances

    Calculate net balances.

    Body: none
    200: balances result
    curl http://localhost:3000/groups/GROUP_ID/balances
    GET /groups/{groupId}/settlements

    Generate optimized settlements.

    Body: none
    200: settlements result
    curl http://localhost:3000/groups/GROUP_ID/settlements
